Flows for generic command sanity checks:
    flow 1. SET(k, v) -> DEL(k) -> GET(k) -> key not found
    flow 2. DEL(k) -> key not found
    
    flow 3.SET(k, v) -> TYPE(k) -> type k
    flow 4. TYPE(k) -> key not found
    flow 5. SET(k1, v) -> LPUSH(k2, v) -> HSET(k3, f, v) -> TYPE(k1, k2, k3, k4) -> string k1, list k2, hash k3, nil k4

    flow 6. SET(k, v) -> EXPIRE(k, 1) -> expire key after 1 seconds
    flow 7. EXPIRE(k, 1) -> key does not exist

    flow 8. SET(k, v) -> EXPIRE(k, 1) -> PERSIST(k) -> persist k
    flow 9. PERSIST(k) -> key not found

    flow 10. SET(k, v) -> EXPIRE(k, -1) -> time is negative
